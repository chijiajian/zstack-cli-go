# 3.1: 生成兼容报表习惯的 VM 对象

**Story ID:** 3.1

**Status:** done

> 单次开发会话范围（约2–8小时）；本文件仅规划。前置依赖完成后实施，不包含真实云操作或发布。

## Story

As a **VMware 迁移管理员**, I want **得到 Name、NumCpu、MemoryGB、PowerState 等明确类型的对象**, so that **保留现有报表处理逻辑**。

## Acceptance Criteria

<!-- LOCKED：外部开发工具不得修改。 -->

1. 给定合法 CLI 实例 JSON 及当前连接身份，当进行投影时，则逐项输出 PSTypeNames 包含 Cloud.Automation.VM 的对象；Id（UUID 身份）、Name、NumCpu、MemoryGB、PowerState、RawState 及连接引用均按架构契约赋值，不声称是 VMware 类型。
2. 给定 memorySizeBytes=1610612736、cpuNum=2，当投影时，则 MemoryGB=1.5、NumCpu=2；缺失可选数值为 null，不解析现有 memorySize 格式化字符串，不把缺失值变成零。
3. 给定 Running、Stopped、Paused、Destroyed 或未知状态，当投影时，则前两者分别映射 PoweredOn/PoweredOff，其余为 Unknown 并保留 RawState；缺少有效 uuid 或实例结构非法时产生协议错误，不输出可写对象。
