# 5.2: 生成内置CLI的品牌发行包

**Story ID:** 5.2
**Epic:** 5
**Slug:** bundled-package
**Status:** done

> 一个开发会话（约2–8小时）目标；若实作发现超过一天，先在规划中拆分，不扩大契约。

## Story

作为 **OEM 安装用户**，我希望 **安装一个包取得模块与CLI**，从而 **无需另装运行依赖**。

## Acceptance Criteria

<!-- LOCKED: 未经明确规划更新，不修改验收契约。 -->

1. 给定核心、品牌与已构建CLI，生成一致名称的manifest/module/品牌入口/导出表/bin/许可证及版本能力清单；每个命令模板只有薄转发。
2. 给定两个测试品牌，除允许的品牌/入口资源外核心哈希一致；导出表只含实现存在且能力已满足的函数。
3. 给定缺失或不匹配CLI、非Windows-amd64首版目标，构建失败；包不含.env、session、客户响应或测试秘密，校验值不冒充签名信任。

## Tasks / Subtasks

- [x] 生成品牌入口与自包含包 (AC: #1)
- [x] 比较双品牌核心哈希与导出能力 (AC: #2)
- [x] 校验CLI版本/架构并排除敏感产物 (AC: #3)
