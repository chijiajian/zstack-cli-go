# 4.1: 统一逐目标确认与 WhatIf 边界

**Status:** done

> 单次开发会话范围（约2–8小时）；本文件仅规划。前置依赖完成后实施，不包含真实云操作或发布。

## Story

As a **批量运维管理员**, I want **使用熟悉的 WhatIf、Confirm 和 ErrorAction 控制写操作**, so that **既保留 PowerShell 习惯又避免重复确认或误写**。

## Acceptance Criteria

<!-- LOCKED：外部开发工具不得修改。 -->

1. 给定已解析 VM 目标，当写命令使用 -WhatIf 或 WhatIfPreference 时，则可执行必要只读解析但业务写请求数为零，不调用旧 CLI dry-run 来模拟确认，也不把预览当作操作成功。
2. 给定单个或多个目标，当 ShouldProcess 获得允许时，则每个目标最多一次 PowerShell 确认，之后 CLI 用 --yes 禁止二次交互；用户拒绝的目标不执行写或等待。
3. 给定批量中一个目标远端失败，当 ErrorAction 为 Continue 时，则报告单项 ErrorRecord 并可继续后续目标；当为 Stop 时，则终止且后续目标写请求数为零，错误中仅含安全身份。
