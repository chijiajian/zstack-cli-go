# 1.2: 提供安全的 CLI 非交互密码输入

**Story ID:** 1.2
**Epic:** 1
**Slug:** password-stdin
**Status:** done

> 一个开发会话（约2–8小时）目标；若实作发现超过一天，先在规划中拆分，不扩大契约。

## Story

作为 **PowerShell 用户**，我希望 **用 PSCredential 登录且密码不进入进程参数**，从而 **自动化登录可安全组合**。

## Acceptance Criteria

<!-- LOCKED: 未经明确规划更新，不修改验收契约。 -->

1. 给定显式 --password-stdin 和 --username，读取最多64KiB UTF-8字节直到EOF；原样保留空白，拒绝空值、过长或无效UTF-8；不进入终端提示。
2. 给定 --password 或 AK/SK 同时指定，返回参数错误；stdin 模式不从继承凭据回退，错误与日志不含哨兵密码。
3. 给定 --save-password=false --no-switch 和隔离配置，复用现有 LoginAccountContext/锁保存会话且不保存密码；原有终端/参数登录保持兼容，双语帮助与能力参考同步。

## Tasks / Subtasks

- [ ] 隔离凭据来源并增加脱敏回归 (AC: #2)
- [ ] 接入共享登录/配置并同步双语参考与Skill能力检查 (AC: #3)
