## Story

作为 **模块维护者**，我希望 **验证真实PowerShell绑定与包行为**，从而 **交叉编译不再被误当作兼容认证**。

## Acceptance Criteria

- 2026-11-09 — Added Windows matrix and pinned Pester. Local Pester and 10,000-VM benchmark ran on macOS with a development CLI. Windows and combined-process memory evidence remain pending.
- 2026-11-10 — Aligned the Windows CI runtime pins with the offline QA kit and added a reproducible kit builder. QA ZIP scripts passed 31 assertions locally on PowerShell 7.4.13 and 7.6.6. Windows execution is pending.
- 2026-11-10 — Windows Job Object 从进程创建时跟踪独立 PowerShell 基准进程和 CLI 子进程，记录合计提交内存峰值、单进程最大值和计量进程数。基准报告含 512 MiB 门槛；非 Windows 的内存项明确为未采集。Windows 原生峰值待执行。
